# ABC Retail – Customer Retention Analysis

## Project Overview
Power BI dashboard to analyze customer retention, churn, and customer value.

## Tools Used
- Power BI
- Excel
- DAX

## Analysis
- Customer Overview
- Customer Retention Analysis
- Churn Analysis
- Customer Value Analysis

## Key KPIs
- Total Customers
- Total Sales
- Total Orders
- Returning Customers

## Objective
To identify customer retention patterns, churn trends, and high-value customers.
